Hubungkan Google Sheets

  1. Buat Google Sheets baru, buka Extensions → Apps Script.
  2. Tempel isi file Code.gs, lalu Deploy → New deployment → Web app (akses: Anyone).
  3. Salin URL Web App (berakhiran /exec) ke kolom di bawah.

Tanpa URL, data tetap tersimpan di perangkat ini saja. Ekspor PDF dan Excel selalu bisa dipakai.
